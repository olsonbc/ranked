# Ranked

Public site for Ranked, an app for ranking the books, films and TV you've finished, one comparison at a time, and sharing those lists with a small circle of friends.

Live at https://olsonbc.github.io/ranked/:
- `index.html`: about Ranked
- `privacy.html`: privacy policy
- `support.html`: support

Report problems or ask questions in [Issues](https://github.com/olsonbc/ranked/issues).

Film and TV data from TMDB. This product uses the TMDB API but is not endorsed or certified by TMDB.
